# Biblical Animation Studio

## About

Biblical Animation Studio is an AI-powered animation production skill designed to help create cinematic, original biblical animated videos.

It guides Claude through the complete video production process, from biblical research and storytelling to storyboarding, character design, animation, sound design, and final rendering.

## Visual Style

The studio specializes in:

- Cinematic low-poly 3D-inspired illustrations.
- Geometric biblical characters.
- Ancient biblical environments.
- Dramatic lighting and shadows.
- Rich and coordinated color palettes.
- Smooth camera movements.
- Atmospheric backgrounds.
- Meaningful transitions.
- Professional sound design.

The visual direction takes inspiration from the storytelling and animation quality of The Bible Project while maintaining original artwork and creative identity.

## Production Workflow

1. Biblical research.
2. Scriptwriting and narration.
3. Scene-by-scene storyboarding.
4. Character and environment design.
5. Animation development.
6. Camera movement and transitions.
7. Background music and sound effects.
8. Preview and quality control.
9. Final video rendering.

## Technology

Primary animation framework:
- React
- Remotion
- TypeScript
- SVG
- CSS

Additional tools may be introduced when they improve production quality.

## How to Use

Install the skill in Claude and enable it.

Example prompt:

"Create a cinematic animated video about the creation of the world. Research the biblical story and prepare a detailed storyboard before implementing the animation."
